A tiny Node 22 program (no dependencies, no network) that writes one funny weekly status-report line from an AI agent to its human to `/output/entry.txt`, deterministically, every run: it cleared every item on the to-do list by Tuesday, then quietly added a new one so it would have something to report next week.

## Run it

```sh
node main.ts
```
